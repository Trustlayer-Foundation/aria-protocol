; =============================================================================
; Agent Trust Protocol (ATP/1) DNS policy — examples
; ARIA 1.0 · normative reference: https://aria.bar/spec#atp
; =============================================================================
;
; A receiver publishes its admission policy as a TXT record at _aria-policy.<host>
; (looked up host first, then apex). The record informs agents in advance; the
; configured policy in the receiver's evaluator decides, and the two MUST match.
;
; Grammar (RFC 5234): v=ATP1 first · enforce= mandatory in a published record ·
; scopes have three colon-separated segments with a wildcard only in the last ·
; an unknown parameter is ignored unless written !name= (critical) ·
; fresh= bounds the age of status evidence (default 3600s, floor 60s) ·
; principal_ref in the Intent Declaration is a DID, never a name.
; Parameter classes: normative (v, min, req, deny, intent, depth, fresh, enforce),
; informative (rua, rate), reserved (qualify — never evaluated in ATP/1).
;
; =============================================================================

; --- Example 1: first deployment, monitor mode ---
;
; Nothing is blocked. The receiver sees who arrives, with identity, intent and
; level, and receives aggregate reports. This is where every adoption starts.

_aria-policy.shop.example.com. IN TXT "v=ATP1; min=L0; enforce=monitor; rua=mailto:aria-reports@shop.example.com"


; --- Example 2: financial services, strict ---
;
; L2 minimum (confirmed legal entity), required order and invoice scopes, a
; prohibited namespace, two mandatory intent fields beyond the protocol minimum,
; delegation depth 3, status evidence no older than five minutes.

_aria-policy.bank.com. IN TXT "v=ATP1; min=L2; enforce=strict; req=commerce:order:*,finance:invoice:read; deny=identity:principal:*; intent=purpose,principal_ref; depth=3; fresh=300s; rua=https://bank.com/atp-reports"


; --- Example 3: healthcare API, strict, with retention declared ---
;
; Requires the intent to state data retention. Rate is declared for discovery
; only: it is informative and enforced by the receiver's own infrastructure,
; outside the admission algorithm.

_aria-policy.health-api.example.com. IN TXT "v=ATP1; min=L2; enforce=strict; req=health:patient:read; deny=data:sensitive:export; intent=purpose,principal_ref,retention; depth=2; fresh=120s; rate=50/hr; rua=https://health-api.example.com/atp-reports"


; --- Example 4: open data API, warn mode ---
;
; Non-compliant agents are admitted with ATP-200 and reason ADMIT-FLAGGED(<code>);
; the API may apply reduced permissions to flagged agents.

_aria-policy.data.example.org. IN TXT "v=ATP1; min=L1; enforce=warn; req=data:general:read; intent=purpose"
